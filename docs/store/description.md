### English Version (英文版本)

```
GrapeMark - A modern, elegant bookmark manager with powerful tagging and smart statistics.

🚀 Key Features

📚 Smart Bookmark Management
• One-click save current page with auto-detected title and favicon
• Pin important bookmarks for quick access
• Edit, delete, and organize with ease
• Automatic click tracking with detailed history
• Click to open in extension, double-click to open in browser
• Homepage search for quick access to bookmarks

💼 Workstation Groups (NEW in v0.4.0)
• Create workstation groups to organize related bookmarks
• One-click open all bookmarks in a workstation
• Pin frequently used workstations for quick access
• Track workstation usage statistics
• Drag-and-drop to manage bookmarks in workstations

🏷️ Advanced Tag System
• Create custom tags with personalized names and descriptions
• 16-color preset palette with intelligent auto-assignment
• Tag colors adapt to light/dark theme automatically
• Drag-and-drop to assign tags quickly
• Statistics: usage count and click count per tag
• Click tags on homepage to filter bookmarks

📊 Data Analytics & Rankings
• Hot Tags: Discover your most-used tags
• Hot Bookmarks: Quick access to frequently visited sites
• Pinned items displayed prominently
• Real-time statistics updates
• Homepage with quick access to rankings

🔍 Powerful Search & Filter
• Full-text search across titles, URLs, and tag names
• Homepage search mode for quick access
• Filter by single or multiple tags
• Combined search and filter options
• Quick access to pinned content

⚡ Performance Boost (NEW in v0.4.1)
• Virtualized grid lists for Bookmarks and Tags for smoother scrolling with large collections
• Back-to-top button for quick navigation

⚙️ Settings & Customization (NEW in v0.4.0)
• Customize bookmark open mode (new tab or new window)
• Set default open mode for tags and workstations
• Light/Dark theme with automatic system preference detection
• Sidebar navigation for better organization
• ESC key and button to exit settings
• About section shows current version and install/update date (NEW in v0.4.1)

🔄 Import & Export
• Export all data as JSON (with optional click history)
• Export includes workstations and all settings
• Import in incremental or overwrite mode
• One-click import from Chrome bookmarks with multi-parameter sync
• Automatic duplicate detection and ID mapping

🎨 Modern Interface
• Clean card-based design with rounded corners
• Sidebar navigation replacing top menu
• Responsive layout for all screen sizes
• Drag-and-drop sidebar for tag and workstation management
• Context menu integration for quick access
• FAB button on homepage for quick creation
• Smooth animations for better user experience

💾 Privacy First
• All data stored locally using chrome.storage.local
• No data sent to external servers
• Full control over your data
• Easy backup via export feature
```

## 📌 Usage Instructions (使用说明)

### For Chrome Web Store Submission (用于 Chrome Web Store 上架)

1. **Short Description (简短描述)**
   - 在 Chrome Web Store 开发者控制台的"简短描述"字段中
   - 粘贴上方"Short Description"部分的任一推荐版本
   - 注意字符数限制：132 个字符

2. **Full Description (完整描述)**
   - 在"详细描述"字段中
   - 复制上方"Full Description"部分的内容
   - 根据目标用户选择英文或中文版本，或同时包含两种语言

3. **Tips (提示)**
   - 可以使用 Markdown 格式，但部分 Markdown 语法可能不被支持
   - Emoji 图标在 Chrome Web Store 中可以正常显示
   - 建议使用项目符号（•）而非 Markdown 列表符号
   - 可以先在预览中查看效果，再进行最终提交
